# 資產紀錄：階段 2（存款頁、投資頁，接上真實資料）

目前有畫面的是「存款」「投資」「設定」。總覽、保險、計畫還是占位頁（只顯示資料筆數），會在後續階段實作。階段 1 的內容（資料層、備份還原、匯率、設定頁）都保留，說明在下面。

## 這個階段完成的事
- 資料庫（IndexedDB 版本 2）：存款、股票、債券與基金與其他資產、保險、計畫、資產快照六張資料表；寫入時會檢查欄位格式，格式不對的資料寫不進去。
- 金額一律用整數儲存（`js/money.js`）：金額 ×100、股數 ×10000、股價與成本 ×100、年利率 ×1000（1.6% 存成 1600）。
- 整庫備份：匯出完整備份；匯入時檢查 app 識別、版本、每筆資料的格式與重複 id；可選「合併匯入」（依 id 去重、保留較新的一筆）或「完整還原」；合併前會預覽各資料表的筆數。
- 匯率（`js/rates.js`）：open.er-api.com 自動取得（連網且超過 12 小時沒更新才抓）、手動覆蓋、恢復自動、離線沿用上次的值；沒有任何匯率時會警告，不會悄悄用錯的數字。
- 備份提醒（預設 14 天）、儲存空間與持久儲存、安裝說明、語言（繁中／English／日本語）與外觀。
- 測試用：「載入範例資料」「清除全部資料」，正式版會移除。

## 這個階段新增的事（相對於階段 1）
- 存款頁：活存與定存、TWD／USD／JPY；摘要（總額、活存與定存小計、未到期定存的預估到期利息、依幣別）；活存與定存圓環圖；定存到期提醒；活存餘額超過 7 天沒更新的警告；批次更新活存餘額（即時顯示變動百分比，20% 以上提醒確認）；新增、編輯、就地確認刪除；調整順序（▲▼，存檔後重新整理仍保留）。
- 投資頁：股票（台股、美股、零股與美股碎股到小數 4 位）、債券與基金、其他資產；損益紅漲綠跌（正負號一併顯示）；台股與美股圓環圖；批次更新股價與債券基金價值；備註；調整順序；新增時同一市場不能有重複代號。
- 所有金額用整數儲存、市值用整數運算（股數 × 股價），不會有小數誤差。
- 外幣換算用設定頁的匯率；如果沒有匯率，該筆外幣會被排除並顯示警告，不會悄悄當成 0 或用錯的數字。
- 英文與日文：這兩頁的文字目前只有繁體中文，English、日本語的完整翻譯放在階段 6。設定頁的翻譯維持完整。

## 更新哪些檔案、要不要載入兩次、有沒有資料遷移
- 新增：`js/ui.js`（共用畫面工具）、`js/deposit.js`、`js/invest.js`。
- 修改：`index.html`（多載入三個檔案）、`js/app.js`、`js/money.js`（美元金額一律顯示兩位小數，例如 US$ 4,293.30）、`sw.js`（快取名稱 `at-v2` → `at-v3`）。
- 沒變：`js/db.js`、`js/rates.js`、`js/sample.js`、`js/i18n.js`、`i18n/dict.js`、`css/style.css`、`manifest.webmanifest`、`icons/`。
- 做法：用這包的檔案覆蓋儲存庫裡同名的檔案，並新增三個檔案。

- 資料遷移：沒有。資料庫版本維持 2，階段 1 建立的資料（包含範例資料）都會保留，並顯示在存款頁與投資頁。

## 資料結構摘要（後續階段照這個做）
| 資料表 | 主要欄位 |
|---|---|
| accounts 存款 | t（D 活存／T 定存）、bank、n、c（TWD／USD／JPY）、v、note、at；定存另有 rate、start、mat |
| holdings 股票 | m（TW／US）、sym、n、sh、cost、price、at、note |
| others 債券、基金與其他 | k（bond／fund／other）、n、c、v、note、at |
| insurance 保險 | k、co、n、who、c、prem、mo（每幾個月繳一次）、due、end、note、ad |
| plans 計畫 | name、target、date、mode（link／manual）、src、amt、at、note |
| snapshots 快照 | date、cash、stock、bond、other、total、items、rates |

每筆都有 `id`、`updatedAt`；可手動排序的資料表另有 `ord`。meta 存最後修改時間、上次備份時間、設定與匯率。

## 與旅遊規劃不衝突的識別字串
| 項目 | 資產紀錄 | 旅遊規劃（對照） |
|---|---|---|
| IndexedDB 名稱 | `asset-tracker` | `trip-planner` |
| localStorage 前綴 | `at-` | `tp-` |
| 快取名稱 | `at-v2`（只清自己前綴的舊快取） | `tp-v4`、`tp-tiles` |
| 匯出檔 app 識別 | `asset-tracker` | `trip-planner` |
| manifest 與圖示 | 資產紀錄、深色長條圖 | 旅遊規劃 |

提醒：旅遊規劃目前的 `sw.js` 會刪掉「所有不是自己的快取」，更新它時會連帶清掉本 App 的離線快取。建議之後把它的清理改成只刪 `tp-` 開頭的快取。

## 實測清單（請在手機與電腦各做一次）
**存款頁**
1. 新增一個台幣活存與一個美元活存：美元那筆要顯示「≈ NT$」，頁面最上方的總額有算進去。
2. 新增一個定存（填本金、年利率、起日、到期日）：要顯示「預估到期利息」與「N 天後到期」；到期日設成昨天，要出現「已過到期日」的警告。
3. 按「批次更新活存餘額」：只填其中一筆，儲存後那筆更新、另一筆維持原樣；輸入時要看到變動百分比。
4. 設定 → 調整順序（▲▼）：移動後重新整理網頁，順序要還在。
5. 編輯一筆但不改金額：更新日期不變；改了金額：更新日期變成今天。

**投資頁**
6. 新增台股（例如 2330）與美股（例如 VOO，股數填 8.25）；損益正的是紅色、負的是綠色；把現價改低，損益要變綠色。
7. 美股那筆要顯示「≈ NT$」；股票圓環圖只有台股與美股兩塊。
8. 重複輸入同一個代號要被擋下；台股股數填 1000.5 要被擋下。
9. 批次更新價格與價值：股票現價與債券基金價值都能更新；填 -1 要被擋下。
10. 新增債券與基金、其他資產各一筆，並試調整順序與刪除。

**匯率與備份**
11. 關閉網路並清除匯率（或第一次使用且離線）時，有外幣的頁面要出現「沒有匯率」警告，且合計不包含外幣。
12. 匯出完整備份 → 清除全部資料 → 匯入備份：存款與投資頁的資料要完整回來。

**畫面**
13. 手機：輸入金額時跳出數字鍵盤；批次更新時按 Enter 會跳到下一欄；▲▼ 好按。
14. 淺色與深色：圓環圖顏色、紅綠損益都看得清楚。
