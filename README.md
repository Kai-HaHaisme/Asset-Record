# 資產紀錄 v1.0.0

個人資產紀錄工具：存款、股票、債券與基金、保險、財務計畫，加上資產快照與走勢圖。純 HTML／CSS／JavaScript，沒有框架、沒有建置工具、沒有後端；資料只存在你自己的裝置（手機或電腦的瀏覽器）裡。以 PWA 形式放在 GitHub Pages，手機可「安裝」成 App，離線也能用。

介面語言：繁體中文（預設）、English、日本語，在「設定」切換。你自己輸入的名稱與備註不會被翻譯。

## 功能總覽
- **總覽**：目前總資產與較上次記錄的變化（紅漲綠跌）、資產分布圓環圖、記錄這次資產（快照）、補登過去、走勢圖（近 6 個月／近 1 年／全部，總額或各類別）、快照紀錄與明細、90 天內到期與繳費。
- **投資**：台股與美股（零股、碎股）、損益、債券與基金、其他資產；股價與價值手動輸入並可批次更新；調整順序。
- **存款**：活存、定存、外幣；預估到期利息；到期提醒；批次更新活存餘額。
- **保險**：保單清單、年繳換算、狀態標籤（未繳／本期已繳／分期中／已繳清／已終止）、標記已繳費、保單卡（繳費紀錄、保障內容與保額、終止與恢復）。保險不計入總資產。
- **計畫**：目標存款，進度可連結資產或手動輸入。
- **設定**：語言與外觀、匯率（自動＋手動）、加密備份與還原、App 鎖（PIN）、儲存空間、安裝說明。

## 一、第一次部署到 GitHub Pages
1. 登入 GitHub，右上角「＋」→「New repository」。Repository name 填 `asset-tracker`，選 **Public**，按「Create repository」。
2. 在新儲存庫的頁面按「uploading an existing file」。先把壓縮檔解開，**把資料夾裡面的內容**（`index.html`、`css`、`js`、`i18n`、`icons`、`manifest.webmanifest`、`sw.js`、`README.md`）全部拖進去——不是拖外層那個資料夾，`index.html` 必須在儲存庫最上層。按「Commit changes」。
3. 到儲存庫的「Settings」→「Pages」。Build and deployment 的 Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1 到 2 分鐘，Pages 頁面上方會出現網址，格式是 `https://你的帳號.github.io/asset-tracker/`。用這個 **https** 網址開啟。
5. **要載入兩次**：第一次載入會安裝離線功能，第二次載入才完整生效。之後到「設定」最下方的「關於」確認版本是 1.0.0。

注意：
- 據我所知，免費的 GitHub 帳號要用 Pages 必須是公開儲存庫，請你確認自己的帳號方案。程式碼公開不會洩漏你的資料，因為資料只存在你的裝置裡。
- **絕對不要把備份檔（.json）上傳到這個儲存庫或任何公開的地方。**
- 儲存庫名稱或帳號名稱一旦改變，網址就會變，而資料綁定網址，舊資料會「看不到」（沒有消失，改回原網址就會回來）。真的要改，請先匯出備份。

## 二、安裝成 App
- Android（Chrome）：瀏覽器選單 →「安裝應用程式」或「加到主畫面」。
- iPhone（Safari）：點下方「分享」→「加入主畫面」。
- 電腦（Chrome、Edge）：網址列右側的「安裝」圖示。

資料是綁在「網址＋瀏覽器」上的：
- 手機的 Safari 與「加入主畫面的 App」是分開的，資料不互通；手機與電腦的資料也是分開的。請固定用其中一個，要搬資料就用「匯出備份 → 匯入」。
- 據我所知，iPhone 的 Safari 對長時間沒開啟的網站可能清除網站資料，加入主畫面的 App 則不受影響；這點我沒辦法在這裡驗證。總之請定期匯出加密備份。

## 三、之後更新程式
我之後給你的更新壓縮檔都會寫明：更新哪些檔案、要不要載入兩次、有沒有資料遷移。一般流程：
1. 先到「設定」匯出一份加密備份（保險起見）。
2. 解開新的壓縮檔。到 GitHub 儲存庫按「Add file」→「Upload files」，把有更新的檔案拖進去（同名檔案會被覆蓋），按「Commit changes」。
3. 等 1 到 2 分鐘，開啟 App **兩次**。
4. 到「設定」→「關於」確認版本號已經是新的。

版本號有兩處要一起改（我做更新時會一併處理）：`sw.js` 開頭的 `VERSION`，以及 `js/app.js` 的 `APP_VERSION`。快取名稱就是 `at-` 加版本號，新版啟用時會自動清掉舊版快取，而且只清 `at-` 開頭的，不會動到旅遊規劃的快取。

## 四、離線怎麼運作
- 第一次載入（以及每次更新後）需要連網。之後離線也能開啟、查看與新增資料。
- 連得上網時，程式會向伺服器確認並用最新檔案；網路很慢（超過 4 秒）或斷網時改用快取。
- 離線時不能更新匯率，會沿用上次取得的匯率（沒有任何匯率時，外幣項目不會被悄悄當成 0，頁面會警告）。
- 股價是手動輸入，不需要網路。

## 五、資料與備份
- 備份檔預設加密（AES-256-GCM），密碼至少 8 個字元。**忘記備份密碼就無法還原，沒有任何辦法找回。**
- 匯入時可選「合併匯入」（依記錄 id 去重，保留較新的，不會刪除任何資料；你在本機刪掉但備份檔裡還有的記錄會被加回來）或「完整還原」（先清空再還原）。
- 清除瀏覽器的網站資料、解除安裝、換瀏覽器都可能讓資料消失，請定期備份（預設每 14 天提醒）。
- 快照存下每個項目的名稱與市值，日後刪掉某個帳戶或股票，歷史走勢與明細不會變。

## 六、安全性與限制
- **PIN 鎖只能防止旁人隨手打開 App，不等於加密儲存**：資料仍以明文存在這個瀏覽器的資料庫裡，拿到你的裝置又有技術的人仍然讀得到；4 到 8 位數字的 PIN 雜湊如果被取走，也能離線暴力破解。請同時使用手機的螢幕鎖定，備份請用加密。
- 忘記 PIN 沒有後門：只能清除這個裝置的資料後，用備份還原。
- 自動鎖定計算的是「離開 App 的時間」，不是「開著不動的時間」；它靠瀏覽器的可見度事件判斷，不同手機（尤其 iPhone）行為可能不同。
- 加密與 PIN 需要 https 網址；用 http 或直接開檔案時會被停用並提示。
- 匯率來源是免費服務 open.er-api.com，可能有用量限制或條款變動；我記得它的條款要求標註來源，設定頁已標註，請你有空再確認一次。匯率只供記錄參考。
- 本工具只做記錄，不構成投資或理財建議；預估利息是簡單估算（本金 × 年利率 × 天數 ÷ 365），實際以銀行計算為準；每月需存沒有考慮投資報酬與利息。

## 七、與「旅遊規劃」放在同一個 github.io 網域
同一個 GitHub 帳號的所有儲存庫共用 `帳號.github.io` 這個網域，瀏覽器會視為同一個來源，所以兩個 App 的識別都刻意不同：

| 項目 | 資產紀錄 | 旅遊規劃 |
|---|---|---|
| IndexedDB 名稱 | `asset-tracker` | `trip-planner` |
| localStorage 前綴 | `at-` | `tp-` |
| 快取名稱 | `at-` ＋版本號（只清自己的） | `tp-` 開頭 |
| 匯出檔 app 識別 | `asset-tracker` | `trip-planner` |
| 圖示與 manifest 名稱 | 深色長條圖、資產紀錄 | 旅遊規劃 |

**建議**：旅遊規劃目前的 `sw.js` 會刪掉「所有不是自己的快取」，旅遊規劃更新時會連帶清掉本 App 的離線快取（資料不會掉，只是要再連網載入一次才恢復離線）。建議之後把旅遊規劃的清理改成只刪 `tp-` 開頭的快取，我可以給你那一行修改。

## 八、檔案結構
```
index.html            單頁外殼
manifest.webmanifest  PWA 設定
sw.js                 離線快取
css/style.css         無印風（淺色、深色）
i18n/dict.js          繁中 → English、日本語 字典
icons/                圖示（180、192、512、512 maskable）
js/money.js           金額與數字工具（整數儲存）
js/db.js              IndexedDB 資料層、格式檢查、整庫匯出入
js/crypto.js          備份加密、PIN 雜湊（Web Crypto）
js/rates.js           匯率
js/ui.js              共用畫面工具
js/i18n.js            語言與外觀
js/lock.js            App 鎖（PIN）
js/overview.js、deposit.js、invest.js、insurance.js、plans.js   各頁
js/app.js             路由、導覽、設定頁、備份提醒
```
金額一律用整數儲存：金額 ×100、股數 ×10000、股價與成本 ×100、年利率 ×1000。

## 九、v1.0.0 實測清單（請在手機與電腦各做一次）
**部署與更新**
1. 照「一」部署後，用 https 網址開啟、載入兩次，「設定」→「關於」顯示版本 1.0.0。
2. 日後第一次更新時，照「三」的流程做，並確認版本號有變。

**離線與安裝**
3. 載入兩次後，開啟飛航模式，重新開啟 App（或重新整理）：所有頁面都能開，能新增、編輯資料。
4. 離線時到「設定」按「立即更新匯率」：要顯示「無法連線，沿用上次的匯率」，原本的匯率不變。恢復網路後再按一次要成功。
5. 離線時匯出備份、匯入備份都能用。
6. Android 與 iPhone 各安裝到主畫面，從主畫面圖示開啟：圖示是深色長條圖、沒有網址列。
7. 網路很差的地方（訊號弱）開啟 App：不會一直空白轉圈，幾秒內就會用快取打開。

**語言**
8. 切到 English、日本語，逐頁看：存款、投資、保險、計畫、總覽、設定、鎖定畫面都沒有殘留中文（你自己輸入的名稱與備註不會被翻譯，屬正常）。

**共存**
9. 同一個 GitHub 帳號若有旅遊規劃：兩個 App 的資料、語言、外觀設定互不影響；在旅遊規劃更新後，回到資產紀錄仍能離線開啟，或至少連網載入一次後恢復。

**前面階段的完整功能**：加密備份與還原、PIN 鎖、保險標記已繳費與保單卡、快照與走勢圖、各頁新增編輯刪除與調整順序，建議再各走一遍。
