# 資產紀錄：階段 1（資料層、導覽、設定頁）

目前有畫面的只有「設定」。其他五頁（總覽、投資、存款、保險、計畫）是占位頁，只顯示資料庫裡各資料表的筆數，畫面會在後續階段實作。

## 這個階段完成的事
- 資料庫（IndexedDB 版本 2）：存款、股票、債券與基金與其他資產、保險、計畫、資產快照六張資料表；寫入時會檢查欄位格式，格式不對的資料寫不進去。
- 金額一律用整數儲存（`js/money.js`）：金額 ×100、股數 ×10000、股價與成本 ×100、年利率 ×1000（1.6% 存成 1600）。
- 整庫備份：匯出完整備份；匯入時檢查 app 識別、版本、每筆資料的格式與重複 id；可選「合併匯入」（依 id 去重、保留較新的一筆）或「完整還原」；合併前會預覽各資料表的筆數。
- 匯率（`js/rates.js`）：open.er-api.com 自動取得（連網且超過 12 小時沒更新才抓）、手動覆蓋、恢復自動、離線沿用上次的值；沒有任何匯率時會警告，不會悄悄用錯的數字。
- 備份提醒（預設 14 天）、儲存空間與持久儲存、安裝說明、語言（繁中／English／日本語）與外觀。
- 測試用：「載入範例資料」「清除全部資料」，正式版會移除。

## 更新哪些檔案、要不要載入兩次、有沒有資料遷移
- 新增：`js/money.js`、`js/rates.js`、`js/sample.js`。
- 修改：`index.html`、`css/style.css`、`js/db.js`、`js/app.js`、`js/i18n.js`、`i18n/dict.js`、`sw.js`（快取名稱 `at-v1` → `at-v2`）。
- 沒變：`manifest.webmanifest`、`icons/`。
- 做法：全新儲存庫（建議名稱 `asset-tracker`）直接上傳整個資料夾內容到根目錄；如果你之前已經上傳過「起始樣板」，就用這包的檔案全部覆蓋。
- 要載入兩次：第一次載入安裝新版 Service Worker，第二次載入才用新版。
- 資料遷移：有。若你的瀏覽器曾開過起始樣板，資料庫會從版本 1 升到 2，起始樣板的「測試記錄」會被刪除（那只是測試資料）。其他情況沒有舊資料需要遷移。

## 資料結構摘要（後續階段照這個做）
| 資料表 | 主要欄位 |
|---|---|
| accounts 存款 | t（D 活存／T 定存）、bank、n、c（TWD／USD／JPY）、v、note、at；定存另有 rate、start、mat |
| holdings 股票 | m（TW／US）、sym、n、sh、cost、price、at、note |
| others 債券、基金與其他 | k（bond／fund／other）、n、c、v、note、at |
| insurance 保險 | k、co、n、who、c、prem、mo（每幾個月繳一次）、due、end、note、ad |
| plans 計畫 | name、target、date、mode（link／manual）、src、amt、at、note |
| snapshots 快照 | date、cash、stock、bond、other、total、items、rates |

每筆都有 `id`、`updatedAt`；可手動排序的資料表另有 `ord`。meta 存最後修改時間、上次備份時間、設定與匯率。

## 與旅遊規劃不衝突的識別字串
| 項目 | 資產紀錄 | 旅遊規劃（對照） |
|---|---|---|
| IndexedDB 名稱 | `asset-tracker` | `trip-planner` |
| localStorage 前綴 | `at-` | `tp-` |
| 快取名稱 | `at-v2`（只清自己前綴的舊快取） | `tp-v4`、`tp-tiles` |
| 匯出檔 app 識別 | `asset-tracker` | `trip-planner` |
| manifest 與圖示 | 資產紀錄、深色長條圖 | 旅遊規劃 |

提醒：旅遊規劃目前的 `sw.js` 會刪掉「所有不是自己的快取」，更新它時會連帶清掉本 App 的離線快取。建議之後把它的清理改成只刪 `tp-` 開頭的快取。

## 實測清單（請在手機與電腦各做一次）
1. 開啟網頁：底部（手機）或左側（電腦）有 總覽、投資、存款、保險、計畫，右上角有「設定」；每個占位頁顯示各資料表 0 筆。
2. 設定 → 匯率：連網時應自動出現美元（約 30 多）與日圓（約 0.2）的自動匯率；按「立即更新匯率」；手動輸入美元匯率後「使用中」改成手動，按「恢復自動」回到自動；開飛航模式再按「立即更新匯率」，應顯示無法連線並保留舊值。
3. 設定 → 載入範例資料：存款頁顯示 3 筆；頁面上方出現「提醒備份」。
4. 匯出完整備份：會下載 `資產紀錄_日期.json`，提醒消失；用文字編輯器打開，金額都是整數。
5. 清除全部資料後，匯入剛才的備份：選「合併匯入」，資料應回來；再試一次「完整還原」。
6. 把備份檔裡的 `"app"` 改成別的字再匯入：應被拒絕。
7. 切換語言與外觀，重新整理後設定仍保留。
8. 載入兩次後開飛航模式重開，應仍可使用；Android 與 iPhone 各試一次安裝到主畫面。
9. 若同帳號已裝旅遊規劃：兩個 App 的資料與語言設定互不影響。

## 已測與未測
- 已測（模擬環境 jsdom＋假的 IndexedDB，共 40 項）：資料庫 v1→v2 升級、欄位格式檢查（小數金額、不支援的幣別等會被擋）、排序、備份匯出內容與整數儲存、匯入驗證（其他 app、較新版本、壞檔、小數金額、重複 id、缺 updatedAt）、合併與完整還原、匯率流程（自動、手動、離線、HTTP 錯誤、壞資料）、英日文字典完整度；金額工具另有 11 項單元測試。
- 未測（我做不到）：真實手機與瀏覽器、真正連到匯率服務（測試用的是模擬回應）、Service Worker 離線與安裝、實際檔案下載與選檔、畫面實際外觀、持久儲存權限。
- 匯率服務是免費服務，可能有用量限制或條款變動；我記得它的條款要求標註來源，設定頁已標註，請你有空再確認一次。
- 合併匯入只新增與更新，不會刪除；你在本機刪掉、但備份檔裡還有的記錄會被加回來（畫面上有提醒）。
