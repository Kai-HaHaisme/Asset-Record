# 資產紀錄：階段 3.1（保險頁加入狀態標籤、分期、保單卡）

目前有畫面的是「存款」「投資」「保險」「計畫」「設定」。只有「總覽」還是占位頁（只顯示資料筆數），會在階段 4 實作。前面階段的內容（資料層、備份還原、匯率、存款頁、投資頁）都保留，說明在下面。

## 這個階段完成的事
- 資料庫（IndexedDB 版本 2）：存款、股票、債券與基金與其他資產、保險、計畫、資產快照六張資料表；寫入時會檢查欄位格式，格式不對的資料寫不進去。
- 金額一律用整數儲存（`js/money.js`）：金額 ×100、股數 ×10000、股價與成本 ×100、年利率 ×1000（1.6% 存成 1600）。
- 整庫備份：匯出完整備份；匯入時檢查 app 識別、版本、每筆資料的格式與重複 id；可選「合併匯入」（依 id 去重、保留較新的一筆）或「完整還原」；合併前會預覽各資料表的筆數。
- 匯率（`js/rates.js`）：open.er-api.com 自動取得（連網且超過 12 小時沒更新才抓）、手動覆蓋、恢復自動、離線沿用上次的值；沒有任何匯率時會警告，不會悄悄用錯的數字。
- 備份提醒（預設 14 天）、儲存空間與持久儲存、安裝說明、語言（繁中／English／日本語）與外觀。
- 測試用：「載入範例資料」「清除全部資料」，正式版會移除。

## 這次更新（階段 3.1）新增的事
- **狀態標籤（金額左邊）**：
  - 「未繳」：繳費日在 30 天內（含已逾期），而且這一期還沒標記已繳費。
  - 「本期已繳」：已標記繳費，而且這次繳費涵蓋的週期還沒結束（月繳到下個月繳費日、年繳整年）。
  - 繳費日還很遠且沒有繳費紀錄時沒有標籤。
  - 「近期要繳的保費」只列「未繳」的保單。
  - 舊的保單沒有繳費紀錄，在你按「標記已繳費」之前不會出現「本期已繳」；繳費日在 30 天內的會先顯示「未繳」。
- **分期**：保單表單新增「總期數」「已繳期數」兩個選填欄位（繳費年期，例如 20 年期年繳填 20，或一筆保費分 12 期都適用）。「已繳期數」只填開始使用本 App 之前已繳的期數；之後每次標記已繳費或補登紀錄會自動加 1。清單顯示「分期中 7/12」，繳滿顯示「已繳清」，已繳清的保單不再出現在近期要繳，也不計入年繳合計。
- **保單卡**：每張保單可按「保單卡」就地展開：
  - 累計已繳金額（本 App 的紀錄）、已繳期數與狀態。
  - 保障內容與保額：可新增多個項目（名稱＋金額）、刪除。
  - 繳費紀錄：繳費日期、對應繳費日、金額、備註；可補登、編輯、就地確認刪除；預設顯示最近 5 筆，可展開全部。
  - 終止保單：選終止日期與原因，保單卡保留在「已終止」頁籤，不計入年繳合計與提醒；可「恢復有效」。刪除只留給輸入錯誤的資料。
- **標記已繳費**：面板新增「繳費日期」與「這次繳的金額」（預設是目前保費，可改），會自動寫入繳費紀錄。

## 更新哪些檔案、要不要載入兩次、有沒有資料遷移
- 修改：`js/insurance.js`、`js/db.js`（保單多了幾個選填欄位的格式檢查）、`css/style.css`（標籤樣式）、`sw.js`（快取名稱 `at-v4` → `at-v5`）。
- 沒變：其他所有檔案。用這包的檔案覆蓋儲存庫裡同名的檔案即可，不用新增檔案。
- 要載入兩次：第一次安裝新版 Service Worker，第二次才用新版。
- 資料遷移：沒有。資料庫版本不變，新欄位都是選填；舊的保單資料與舊備份檔都可以照常使用。

## 資料結構摘要（後續階段照這個做）
| 資料表 | 主要欄位 |
|---|---|
| accounts 存款 | t（D 活存／T 定存）、bank、n、c（TWD／USD／JPY）、v、note、at；定存另有 rate、start、mat |
| holdings 股票 | m（TW／US）、sym、n、sh、cost、price、at、note |
| others 債券、基金與其他 | k（bond／fund／other）、n、c、v、note、at |
| insurance 保險 | k、co、n、who、c、prem、mo（每幾個月繳一次）、due、end、note、ad；選填：status（active／ended）、endedOn、endNote、terms、pt、hist（繳費紀錄）、cov（保障內容） |
| plans 計畫 | name、target、date、mode（link／manual）、src、amt、at、note |
| snapshots 快照 | date、cash、stock、bond、other、total、items、rates |

每筆都有 `id`、`updatedAt`；可手動排序的資料表另有 `ord`。meta 存最後修改時間、上次備份時間、設定與匯率。

## 實測清單（請在手機與電腦各做一次，這次重點是保險頁）
1. 清單：每張保單金額左邊要有標籤。繳費日在 30 天內且還沒標記的是「未繳」；繳費日很遠的沒有標籤。手機畫面太窄時，標籤會換到金額旁邊自動換行，請確認沒有擠在一起。
2. 對一張「未繳」保單按「標記已繳費」：面板要有繳費日期與金額；確認後標籤變「本期已繳」，這張保單從左欄「近期要繳的保費」消失。
3. 新增一張分期保單（總期數 12、已繳期數 7）：顯示「分期中 7/12」；標記已繳費後變 8/12；一路繳到滿，要顯示「已繳清」，「標記已繳費」按鈕消失，年繳合計也不再包含它。
4. 按「保單卡」：看累計已繳金額；新增兩個保障項目（例如「住院日額」2,000）；補登一筆過去的繳費；編輯、刪除那筆紀錄；紀錄超過 5 筆時能展開全部。
5. 終止一張保單：保單卡留在「已終止」頁籤，年繳合計下降，繳費紀錄還在；按「恢復有效」能回來。
6. 匯出完整備份 → 清除全部資料 → 匯入：保單的繳費紀錄、保障內容、終止狀態都要完整回來。
7. 舊的保單（沒有繳費紀錄）在畫面上看起來正常，沒有錯誤。
8. 淺色與深色下，「未繳」標籤（外框）與「本期已繳」標籤（實心）都看得清楚。
