# 資產紀錄：階段 3（保險頁、計畫頁，接上真實資料）

目前有畫面的是「存款」「投資」「保險」「計畫」「設定」。只有「總覽」還是占位頁（只顯示資料筆數），會在階段 4 實作。前面階段的內容（資料層、備份還原、匯率、存款頁、投資頁）都保留，說明在下面。

## 這個階段完成的事
- 資料庫（IndexedDB 版本 2）：存款、股票、債券與基金與其他資產、保險、計畫、資產快照六張資料表；寫入時會檢查欄位格式，格式不對的資料寫不進去。
- 金額一律用整數儲存（`js/money.js`）：金額 ×100、股數 ×10000、股價與成本 ×100、年利率 ×1000（1.6% 存成 1600）。
- 整庫備份：匯出完整備份；匯入時檢查 app 識別、版本、每筆資料的格式與重複 id；可選「合併匯入」（依 id 去重、保留較新的一筆）或「完整還原」；合併前會預覽各資料表的筆數。
- 匯率（`js/rates.js`）：open.er-api.com 自動取得（連網且超過 12 小時沒更新才抓）、手動覆蓋、恢復自動、離線沿用上次的值；沒有任何匯率時會警告，不會悄悄用錯的數字。
- 備份提醒（預設 14 天）、儲存空間與持久儲存、安裝說明、語言（繁中／English／日本語）與外觀。
- 測試用：「載入範例資料」「清除全部資料」，正式版會移除。

## 這個階段新增的事（相對於階段 2）
- 保險頁：保單清單（險種、保險公司、保單名稱、被保險人、保費、繳費頻率、下次繳費日、保障到期日、備註）；年繳保費合計與平均每月（月繳、季繳、半年繳、兩年繳、自訂頻率都換算成一年）；依險種的年繳圓環圖；30 天內與已逾期的保費；90 天內與已到期的保障；險種頁籤；新增、編輯、就地確認刪除、調整順序。保險不計入總資產。
- 繳費頻率：月繳、季繳、半年繳、年繳、兩年繳，另可自訂「每幾個月繳一次」（1 到 120 個月）。
- 標記已繳費：下次繳費日依頻率自動順延，可以手動改日期；1 月 31 日的月繳保單會順延到 2 月 28 日，下一次回到 3 月 31 日，不會一路縮成 28 日；有保障到期日的保單，如果原本和繳費日同一天（例如強制險）就預設一起順延，否則維持不變，也可手動修改。
- 計畫頁（目標存款）：進度來源二選一——連結資產（現金與存款、股票、債券與基金、其他資產四個類別，或個別存款帳戶，金額自動跟著存款與投資頁變）或手動輸入金額（可隨時「更新金額」）；顯示進度條、已存、還差、目標日期倒數、每月需存（還差的金額 ÷ 剩餘月數，沒有考慮投資報酬）；勾了「現金與存款（全部）」時個別帳戶會自動排除避免重複計算；多個計畫連到同一筆資產時會提醒；連結的項目被刪除時會警告；沒有匯率時會警告。
- 英文與日文：保險與計畫頁的文字目前只有繁體中文，完整翻譯放在階段 6。

## 更新哪些檔案、要不要載入兩次、有沒有資料遷移
- 新增：`js/insurance.js`、`js/plans.js`。
- 修改：`index.html`（多載入兩個檔案）、`js/app.js`、`js/ui.js`（新增共用的讀取全部資產函式）、`sw.js`（快取名稱 `at-v3` → `at-v4`）。
- 沒變：其他所有檔案。
- 做法：用這包的檔案覆蓋儲存庫裡同名的檔案，並新增兩個檔案。
- 要載入兩次：第一次安裝新版 Service Worker，第二次才用新版。
- 資料遷移：沒有。資料庫版本不變，之前的資料都會保留。

## 資料結構摘要（後續階段照這個做）
| 資料表 | 主要欄位 |
|---|---|
| accounts 存款 | t（D 活存／T 定存）、bank、n、c（TWD／USD／JPY）、v、note、at；定存另有 rate、start、mat |
| holdings 股票 | m（TW／US）、sym、n、sh、cost、price、at、note |
| others 債券、基金與其他 | k（bond／fund／other）、n、c、v、note、at |
| insurance 保險 | k、co、n、who、c、prem、mo（每幾個月繳一次）、due、end、note、ad |
| plans 計畫 | name、target、date、mode（link／manual）、src、amt、at、note |
| snapshots 快照 | date、cash、stock、bond、other、total、items、rates |

每筆都有 `id`、`updatedAt`；可手動排序的資料表另有 `ord`。meta 存最後修改時間、上次備份時間、設定與匯率。

## 與旅遊規劃不衝突的識別字串
| 項目 | 資產紀錄 | 旅遊規劃（對照） |
|---|---|---|
| IndexedDB 名稱 | `asset-tracker` | `trip-planner` |
| localStorage 前綴 | `at-` | `tp-` |
| 快取名稱 | `at-v2`（只清自己前綴的舊快取） | `tp-v4`、`tp-tiles` |
| 匯出檔 app 識別 | `asset-tracker` | `trip-planner` |
| manifest 與圖示 | 資產紀錄、深色長條圖 | 旅遊規劃 |

提醒：旅遊規劃目前的 `sw.js` 會刪掉「所有不是自己的快取」，更新它時會連帶清掉本 App 的離線快取。建議之後把它的清理改成只刪 `tp-` 開頭的快取。

## 實測清單（請在手機與電腦各做一次）
**保險頁**
1. 新增月繳醫療險（例如 1,850）：頁面上方「年繳保費合計」要是 22,200、平均每月 1,850。
2. 新增一張兩年繳的機車強制險（保費 1,200，保障到期日和下次繳費日同一天）：年繳換算是 600。再新增一張美元保單：要顯示「≈ NT$」並算進合計。
3. 繳費頻率選「自訂」填 18：清單顯示「每 18 個月繳」。
4. 把一張保單的下次繳費日改成幾天前：左欄要出現「已逾期」與警告。
5. 對機車強制險按「標記已繳費」：下次繳費日與保障到期日都應該往後兩年；試著手動改日期再確認。
6. 對 1 月 31 日繳費的月繳保單連按兩次「標記已繳費」：第一次是 2 月 28 日，第二次要回到 3 月 31 日。
7. 險種頁籤、調整順序（重新整理後順序還在）、刪除都能用。

**計畫頁**
8. 新增計畫，選「連結資產」，勾「現金與存款（全部）」與「債券與基金」：已存金額要等於存款頁總額加上債券基金的金額。勾了「現金與存款（全部）」後，個別帳戶應該變灰。
9. 到存款頁改一筆活存的金額，再回計畫頁：進度要跟著變。
10. 再建一個只連結某個存款帳戶的計畫：兩個計畫都要出現「使用相同的資產」提醒。
11. 新增「手動輸入金額」的計畫，用「更新金額」改金額與日期。
12. 把一個連結的存款帳戶刪除：計畫要警告「已經不存在」。
13. 目標日期早於今天：新增時要被擋下；編輯已過期的計畫但不改日期，要能存。

**備份**
14. 匯出完整備份 → 清除全部資料 → 匯入：保險與計畫（包含計畫連結的帳戶）要完整回來；連結的帳戶 id 不變，所以進度還是對的。

**畫面**
15. 手機：數字鍵盤、日期欄位、▲▼ 好操作；淺色與深色下進度條與圓環圖都看得清楚。
